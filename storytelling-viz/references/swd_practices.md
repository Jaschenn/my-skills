## C. 选对图

**C1. 用读者熟悉的图。** 横条、折线、点图通常胜过树图、多个饼图、雷达图。经验法则:比较两个类别超过约 2 秒,就换更简单的图。〔treemaps〕

**C2. 一图不装所有问题,拆成多张。** 每张图回答一个问题、带一段话。别做"瑞士军刀图",比如"堆积柱 + 总量线 + 数据表"。〔different-magnitudes、five-questions、is-your-point-clear〕

**C3. 常见替换(案例里实际做过的):**

| 原图 | 问题 | 改成 |
|---|---|---|
| 多个饼图比较各组构成 | 同一类别在不同饼里位置不同,无法横向比 | 100% 横向堆积条,类别按自然顺序排列;两端各有一条基线 |
| 柱 + 线组合,且双轴 | 计划和实际无法直接比较 | 共用一根轴;"计划 vs 实际"用面积或差值带填充缺口 |
| 堆积柱 + 顶部总量线 | 总量线和柱高重复编码 | 去掉总量线;总量单独画一张折线 |
| 堆积柱看各序列趋势 | 只有最底层有基线 | 拆成多条折线 / 小多图;只比首尾两期时用斜率图 |
| 发散(蝴蝶)条比较两年 | 跨年比较难,也无法扩展到第三年 | 两年并排的分组条;或连接点图;规模差异大时用 % 变化的斜率图 |
| 柱(实际值)+ 两个点(区间上下界) | 粗柱压住细点 | 区间画成一段灰色横条,实际值画成一个点("值在区间内"点图) |
| 竖柱 + 斜着的类别标签 | 难读 | 横向条形 |
| 树图 | 面积和色深都难比较,没有共同基线 | 横向条形,按值排序;只聚焦前几名,其余合并为"其他"或放附录 |
| 表格 / 热力表 | 看不出整体形状 | 时间序列用折线;量级跨度大的计数用单位图(一格 = 一人) |
| 9 条彩色折线(意大利面图) | 互相缠绕 | 灰底加一条高亮;或小多图;配一张"最新一期"横条 |
| 漏斗数字表 + 饼图 | 两者的关系要读者自己算 | 横条漏斗,各阶段之间的流失画成带标签的虚线缺口,右侧用同色拆解流失原因 |

**C4. 量级差异很大时:**
- 用 % 变化,不用绝对值:否则大门店压扁小门店。
- 或者拆成多张图,分别设置合适的刻度。
- 现场讲时可以逐层叠加,每次放大刻度,让"小类到底有多小"被看见。
〔diverging-bar、different-magnitudes〕

**C5. 用"留白"表示机会。** 把"尚未覆盖"的部分画成空心或白色,再用深色粗描边勾出来,读起来就是"还能填满的空间"。标签放在空白段上,不放在已覆盖段上。〔story-about-opportunity〕

## D. 排列与对比

**D1. 要比较的东西放在一起。** 两年对比应该并排,而不是分在中线两侧。〔diverging-bar〕

**D2. 排序要有意义。**
- 有自然顺序的(漏斗阶段、风险等级、严重程度)按自然顺序排。
- 否则按值排序,最差或最好的放在最显眼的位置(顶部或左侧)。
- 永远不要按字母序。
- 焦点对象可以移到第一位。
〔dont-hide、connected-dot、heatmap、diverging-bar〕

**D3. 相关的几张图固定同一刻度。** 同一指标在全国、区域、门店各级用同一个 y 轴范围,不要每张图自动缩放,否则无法横向比较。〔shrinkage-report〕

**D4. 多张图要有版面层级。**
- 每页结构一致:页眉写范围,左上放摘要数字,下方放大的总图,右侧对齐放小的分项图,底部留给洞察。
- 留白分组。
- 二十张一样大、一样权重的图等于没有重点。
〔shrinkage-report、dashboard-to-story〕

**D5. 有参照才有判断。** 在图内画目标线、区域均值,或把"区域均值"作为一根参照柱。〔shrinkage-report、connected-dot〕

## E. 强调与去杂

**E1. 先全部灰,再只给需要的地方上色。** 全灰时如果某个元素"消失"了(如堆积柱顶部的总量线),说明它是冗余的。〔five-questions〕

**E2. 焦点只有一个故事。** 其余系列可以退到背景:灰色、同色系的浅色或透明度。重要的一组移到最显眼的位置。〔dont-hide、heatmap〕

**E3. 历史期用同色系渐浅,当期最饱和。** 当两条灰线会重叠、分不清时,用色调深浅区分,而不是两条一样的灰线。〔shrinkage-report〕

**E4. 标记点和数据标签像加粗字一样省着用。**
- 只标关键点,比如当期、去年同期、前年同期,当期标签更大。
- 所有序列用同一种标记形状。
- 标签颜色和所在的线一致。
〔shrinkage-report〕

**E5. 删除:** 边框、网格线(作者 99% 的情况都删)、3D、多余小数、柱上冗余的数据标签、重复的刻度前缀(如每个刻度都写 "WK")、居中标题、远离数据的图例。坐标轴线淡化为灰色。〔shrinkage-report、five-questions、connected-dot〕

**E6. 色弱安全的色阶。**
- 不用红绿色阶,红和绿在最常见的色弱类型下都偏棕。
- 热力表用"白 → 橙"单向色阶,只让高值显眼;也可以用蓝-白-橙这类发散色阶,但中点用白色。
〔heatmap〕

**E7. 不要虚假精度。** 来自抽样的比率保留到够区分即可,一般两位小数或整数百分比。数字要能顺口念出来。〔heatmap、connected-dot〕

**E8. 坐标轴。**
- 柱状图必须从 0 开始。
- 折线图可以不从 0 开始,但"停在离 0 很近的地方"(如 0.5%)容易误导,这种情况不如直接从 0 开始。
- 轴文字去掉末尾多余的零。
〔shrinkage-report、connected-dot〕

**E9. 小多图(panel)给每个人看自己的那块。**
- 受众是各站点负责人时,小多图让每人都能找到自己的站点,同时还能和其他站点对比。
- 可以给每个小图加状态框定,如"改善 / 持平 / 关注"。
〔heatmap〕

## G. 配图里才看得到的做法(正文没写,但每张终稿都在用)

以下来自逐张查看 14 篇文章的配图(改前、中间步骤、终稿)。

**G1. 图例几乎从不单独出现。** 有两种替代方式:
- 线尾或条旁直接标注;
- 图头一行彩色词,如 "阶段:浏览 | 加购 | **已下单** | **已支付**",词的颜色就是数据的颜色,词之间用灰色竖线分隔。
- 聚焦时,非焦点的词改成灰色;分步讲解时,还没出场的类别也是灰色,所以这行词同时充当"进度条"。
〔dont-hide、diverging-bar、shrinkage、treemaps、different-magnitudes〕

**G2. 两色标题。** 标题大部分是常规字重,只把关键短语加粗并着色,而且这个颜色与图中对应元素一致。也常见"轻引导语 + **粗体主张**"的写法(如 "Opportunity: **expand our training program**")。〔几乎所有终稿〕



**G5. 三级强调。** 焦点项用饱和色;需要比较的项用同色相的浅色;其余用灰色。例如 Customer A 深蓝,B、C 浅蓝,D 灰。〔treemaps、dont-hide、connected-dot〕

**G6. 空心 / 实心。**
- 早期用空心点,当期用实心彩色点(连接点图)。
- 非焦点项的点用空心,焦点项用实心(区间点图)。
- 焦点的类别名也同色加粗。
〔diverging-bar、connected-dot〕

**G7. 基准作为一行。** "区域平均"放进排序里当作普通一行:名称加粗,区间条用深色。不另画一条参考线。〔connected-dot〕

**G8. 只给说明问题的那一段线上色。** 整条线灰色;"改善"只把最后的下降段上色,"关注"只把最近连续上升段上色,线尾加点和同色数值。每行左侧一个彩色竖条写状态(改善/持平/关注),格子标题用同色。〔heatmap〕

**G9. 计划与实际。**
- 计划用灰色虚线,一直延续到期末;实际用粗实线,停在最新月。
- 缺口用同色浅色填充,缺口总量加粗放在线尾。
- 同一页两个面板可以用不同的强调色(左橙、右黑),各讲各的。
〔is-your-point-clear〕

**G10. 条形标注。**
- 数值写在条内右端,用白字;条太短时放到条外,改灰字。
- 次数写在条内,占比用灰字写在条外。
- 横条图的数值轴放在顶部,只有浅灰刻度,没有网格。
〔heatmap、connecting-the-dots、treemaps、dont-hide〕

**G11. 机会条旁的标注句。** 每根条右侧紧贴条尾写一句灰色说明,只把关键数字加粗,并用"机会"的颜色。这些句子随条长自然形成阶梯。〔opportunity〕

**G12. 轴的说明。**
- 轴标题小号放在轴的起点:y 轴在左上,x 轴在左下。
- 不熟悉的图在轴两端写"低 / 高"。
- 时间轴用两层:月份在上,年份只在第一个月和 1 月下方出现。
〔quick-presentation、is-your-point-clear、five-questions、different-magnitudes〕

**G13. 只标端点。** 折线只在首尾(或峰值和最新值)加点和加粗数值。斜率图在两端写数值,中点用灰色斜体写变化率。〔different-magnitudes、dashboard-to-story、five-questions〕

**G14. 关注程度渐变。** 风险类别按"关注程度"上色:低风险是浅灰、中灰,高风险依次是浅橙、深橙、红。颜色表达"严重程度",而不只是区分类别。〔different-magnitudes〕

**G15. 单位图细节。**
- 先画全灰的网格(总体),再在下一页按类别填色。
- 标签放在右侧,对齐该类第一行,与格子同色。
- 拆成小块时,所有块用相同的格子大小,块的大小本身就是数量。
〔unit-chart〕

## 在本 skill 中的落地

| 实践 | 用哪个函数 / 参数 |
|---|---|
| 排名 / 一个时点的构成 | `bar_rank(..., highlight=, top_n=)`:按值排序、焦点色 + 其余灰、"其他"合并、条内/条外数值自动判断 |
| 值在区间内 | `range_dot(..., flag="below")`:区间条 + 点,越界行三处同色,`bench=` 基准行 |
| 斜率图(首尾两期) | `slope(..., mode="change", groups=)`:两端直接标注、自动防重叠 |
| 连接点图(两期对比) | `dumbbell(...)`:空心 = 早期、实心 = 当期,按末期排序,`chart.legend` 给出图例行 |
| 100% 横向堆积 | `stacked_100(..., order=, focus_cat=, focus_parts=)`:自然顺序 + 单色渐变,两级弱化 |
| 多序列趋势 | `line_trend(..., highlight=)`:灰底 + 高亮,线尾直接标注;`band=` 置信带;`ref=` 目标线 |
| 小多图 | `small_multiples(...)`:同一 y 刻度,灰色背景线 = 其他组,只在首列/末行标刻度 |
| 计划 vs 实际 / 贡献拆解 | `waterfall(...)` 或 `line_trend(..., ref=)`;特殊版式用 Canvas 自画 |
| 热力表 | `heatmap(...)`:白 → 单色,2–98 分位色阶,深色格自动白字,列多时标签自动旋转 |
| 分布 | `distribution(kind="box" / "strip" / "hist")` |
| 估计值与区间(森林图) | `point_range(..., ref=0)` |
| 文字和数据同色 | 图头图例行用 `chart.legend`(彩色词);焦点类别名自动同色加粗 |
| 漏斗、单位图等特殊版式 | 用 `charts.Canvas` + `charts.Frame` 自画(见 SKILL.md "自定义图") |
